# 新工具清单（缺口对比 + 优先级路线图）

> 配套文档：`docs/c-end-top100-tools.md`
> 目标：将 C 端 TOP100 与平台现有工具对比，产出「待开发清单」，并标注本轮已交付项。

## 一、现有工具与 TOP100 的重叠情况

平台现有 **27 个工具 / 40 个组件**，绝大多数为开发者向。与 TOP100 的重叠仅约 **12 项**：

| TOP100 分类 | 已覆盖项 | 说明 |
|------|------|------|
| 编码转换 | Base64、URL、JWT、Unicode、MD5/SHA | ✅ 基本覆盖 |
| 时间日期 | 时间戳、日期格式化 | ⚠️ 缺倒计时/日期计算/农历 |
| 网络工具 | IP 查询、Ping | ⚠️ 缺短链/测速/Whois/SSL |
| 密码安全 | 密钥/ID 生成 | ⚠️ 缺强度检测 |
| 文档处理 | DOCX/Excel/PDF→MD | ⚠️ 仅「转 MD」，缺合并/压缩/拆分/加密 |
| 图片处理 | 证件照生成 | ⚠️ 仅 1 项，缺压缩/去背/二维码 |

**结论**：TOP100 中约 **80+ 个高频工具**为平台空白，扩展空间巨大。

## 三、本轮交付说明

- **新增 14 个纯前端工具**，覆盖「计算 / 颜色 / 文本 / 趣味 / 生活 / 密码」6 大新增分类。
- **无需后端改动**：沿用仓库既有「纯前端组件」模式（同 进制转换 / Cron 等），仅新增 `.vue` 组件并在 `App.vue` 接线。
- **构建**：`web/` 下 `npm run build` 重新生成 `dist`，再 `go build` 重新嵌入二进制即可生效。
- **验证**：构建后已确认新组件被打包进 `dist`，服务可正常启动并对外提供页面。

## 四、建议的后续节奏

1. **P1（1-2 周）**：补齐轻量库类工具（二维码识别、图表、农历、繁简/拼音）。
2. **P2 分批（按月）**：优先做「图片压缩/格式转换」「PDF 合并拆分压缩」这类高频且可自托管后端的工具；AI/翻译/天气等需密钥的放在最后，并做成可配置接入。
3. **运营**：在侧边栏增加「热门 / 新上线」标签，收集使用数据反哺优先级。
