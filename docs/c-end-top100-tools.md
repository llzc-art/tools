# C 端用户常用在线工具 TOP100 分析

> 分析目标：梳理普通消费者（C 端、非技术用户）日常最高频使用的在线小工具，为「攻城师天梯」工具平台从「开发者向」扩展到「大众向」提供依据。
> 方法：结合国内外主流工具站（Smallpdf、iLovePDF、Remove.bg、TinyPNG、Convertio、Tool.lu、草料二维码、百度/360/搜狗工具箱、aigei.com 等）与多轮检索交叉验证，按使用场景分类归纳。

## 三、关键洞察

1. **平台当前缺口巨大**：现有 27 个工具几乎全是「开发者向」（编码/加解密/API/文档解析/网络探测）。在 TOP100 中，仅「编码转换」「部分网络工具」「部分时间日期」与现有重叠，**约 80 个高频 C 端工具完全缺失**。
2. **最高性价比的扩展方向**：计算类（单位换算/计算器/BMI/日期计算）、颜色类、文本类（字数/去重/排版）、趣味随机类、生活类（二维码/TTS/倒计时）——这些均可在**纯前端**实现，无需后端、无需密钥、零外部依赖，可立刻补齐。
3. **需要外部能力的工具**（放入迭代 backlog）：OCR、AI 画图/对话、翻译、天气、快递、PDF 重处理、音视频转码等，需接入 API 或重量级库，建议分期接入。
4. **二维码是 C 端标志性工具**：使用频次极高且可前端生成，优先实现。
