# 需求规格说明书

## 1. 项目概述

### 1.1 项目名称

攻城师天梯

### 1.2 项目描述

攻城师天梯是一个基于 Web 的在线工具集合平台，提供日常开发与工作中常用的各类小工具，涵盖开发调试、AI 对话、时间处理、编解码、加密生成、数据处理、网络工具等 7 大分类 14 个工具。用户通过浏览器即可快速使用这些工具，无需安装任何客户端软件。

### 1.3 项目目标

1. 提供轻量、高效的在线工具集合
2. 响应速度快，操作简单直观
3. 支持后续扩展更多工具类型
4. 提供标准 RESTful API 接口，方便集成调用
5. 单文件部署，开箱即用

## 2. 用户角色

| 角色     | 描述                                 |
|---------|--------------------------------------|
| 普通用户 | 通过浏览器访问工具页面，使用各类小工具  |
| 开发者   | 通过 API 接口调用工具功能，集成到自己的项目中 |

## 3. 功能需求

### 3.1 API 调试工具

- **FR-API-001**：支持 GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS 七种 HTTP 方法
- **FR-API-002**：支持多种请求 Body 类型（none/JSON/x-www-form-urlencoded/form-data/Raw）
- **FR-API-003**：支持 Bearer Token 和 Basic Auth 认证
- **FR-API-004**：支持环境管理，每套环境可配置 Base URL、变量和公共 Headers
- **FR-API-005**：支持分组和接口管理，每个接口独立保存配置
- **FR-API-006**：支持后端代理模式，绕过浏览器跨域限制
- **FR-API-007**：支持 `{{变量名}}` 模板语法，运行时自动替换为环境变量值
- **FR-API-008**：支持从 cURL 命令导入，自动解析填充请求参数
- **FR-API-009**：支持 OpenAPI/Swagger 导入，自动生成分组和接口
- **FR-API-010**：支持 multipart/form-data 文件上传
- **FR-API-011**：响应自动检测内容类型（JSON/XML/HTML/CSS/Image/Media/Binary/PDF/Text）
- **FR-API-012**：JSON 响应自动格式化并语法高亮（key/string/number/boolean/null 分色）
- **FR-API-013**：XML/HTML 响应自动格式化并语法高亮（标签/属性/字符串/注释分色）
- **FR-API-014**：图片响应预览、音视频响应播放
- **FR-API-015**：格式化/压缩切换，一键复制响应内容
- **FR-API-016**：所有配置状态持久化到后端数据库

### 3.2 LLM 对话工具

- **FR-LLM-001**：支持多套 LLM 配置管理（API 地址、模型、API Key、温度、最大 Tokens）
- **FR-LLM-002**：支持流式对话（SSE），逐字输出
- **FR-LLM-003**：支持非流式对话
- **FR-LLM-004**：支持 Markdown 渲染和代码高亮
- **FR-LLM-005**：对话历史按配置 ID 持久化存储
- **FR-LLM-006**：支持设置默认配置，打开即用
- **FR-LLM-007**：兼容 OpenAI API 格式

### 3.3 时间戳工具

- **FR-TS-001**：获取当前 Unix 时间戳（秒级）
- **FR-TS-002**：获取当前 Unix 时间戳（毫秒级）
- **FR-TS-003**：将 Unix 时间戳转换为可读时间格式
- **FR-TS-004**：将可读时间格式转换为 Unix 时间戳

### 3.4 时间格式化工具

- **FR-TF-001**：支持多种时间格式的互相转换
- **FR-TF-002**：支持自定义时间格式模板
- **FR-TF-003**：支持不同时区的时间转换

### 3.5 Base64 编码工具

- **FR-B64-001**：对输入字符串进行 Base64 编码
- **FR-B64-002**：支持 4 种编码模式（Standard/Base64URL/无填充 Standard/无填充 Base64URL）
- **FR-B64-003**：返回编码后的结果

### 3.6 Base64 解码工具

- **FR-B64-004**：对 Base64 编码的字符串进行解码
- **FR-B64-005**：处理非法输入时返回明确错误信息
- **FR-B64-006**：返回解码后的原始字符串

### 3.7 URL 编解码工具

- **FR-URL-001**：对字符串进行 URL 查询参数编码
- **FR-URL-002**：对 URL 编码的字符串进行解码

### 3.8 Hash 哈希工具

- **FR-HASH-001**：支持 MD5 哈希计算
- **FR-HASH-002**：支持 SHA1 哈希计算
- **FR-HASH-003**：支持 SHA256 哈希计算
- **FR-HASH-004**：支持 SHA512 哈希计算

### 3.9 ID 生成工具

- **FR-ID-001**：生成 UUID v4（标准 8-4-4-4-12 格式）
- **FR-ID-002**：生成 UUID v4 无横线格式
- **FR-ID-003**：支持雪花算法（Snowflake）分布式 ID 生成，可自定义起始时间和节点 ID
- **FR-ID-004**：支持随机字符串生成（11 种预定义字符集）
- **FR-ID-005**：支持自定义字符集生成随机字符串
- **FR-ID-006**：支持批量生成（1-100 个）

### 3.10 JSON 工具

- **FR-JSON-001**：JSON 格式化（美化输出）
- **FR-JSON-002**：JSON 压缩（单行输出）
- **FR-JSON-003**：压缩后统计节省字节数

### 3.11 URL 解析/构建工具

- **FR-UC-001**：URL 组件编码（PathEscape）
- **FR-UC-002**：URL 组件解码（PathUnescape）
- **FR-UC-003**：URL 解析为各组成部分（协议、主机、端口、路径、查询、锚点）
- **FR-UC-004**：从各组成部分构建完整 URL

### 3.12 Unicode 编解码工具

- **FR-UNI-001**：将非 ASCII 字符编码为 Unicode 转义序列
- **FR-UNI-002**：将 Unicode 转义序列解码为原始字符

### 3.13 IP 查询工具

- **FR-IP-001**：查询 IP 地址版本（IPv4/IPv6）
- **FR-IP-002**：CIDR 子网计算（网络地址、子网掩码、可用主机数）

### 3.14 正则表达式工具

- **FR-REGEX-001**：正则表达式匹配测试，返回所有匹配项
- **FR-REGEX-002**：正则表达式替换

### 3.15 字符串工具

- **FR-STR-001**：字符串统计（字符数、字节数、行数、词数、中文数）
- **FR-STR-002**：字符串大小写转换
- **FR-STR-003**：命名风格转换（camelCase、snake_case）
- **FR-STR-004**：字符串与十六进制互转

### 3.16 JWT 解码工具

- **FR-JWT-001**：解码 JWT Token 的 Header 部分
- **FR-JWT-002**：解码 JWT Token 的 Payload 部分
- **FR-JWT-003**：校验 JWT 格式有效性
- **FR-JWT-004**：自动识别时间戳字段（iat/exp/nbf），转换为可读时间和相对时间

### 3.17 健康检查

- **FR-HC-001**：提供服务健康检查接口 `/api/ping`

## 4. 非功能需求

### 4.1 性能要求

- **NFR-P-001**：API 接口平均响应时间 < 50ms
- **NFR-P-002**：支持并发请求，单实例 QPS ≥ 1000
- **NFR-P-003**：基于 fasthttp 高性能框架，充分利用其零内存分配特性

### 4.2 可用性要求

- **NFR-U-001**：服务可用性 ≥ 99.9%
- **NFR-U-002**：单个工具操作不超过 2 步即可完成

### 4.3 安全要求

- **NFR-S-001**：API 接口需对输入参数进行校验，防止注入攻击
- **NFR-S-002**：对异常输入返回通用错误信息，不暴露系统内部细节
- **NFR-S-003**：API 代理模式禁止请求内网地址（防止 SSRF）

### 4.4 可扩展性要求

- **NFR-E-001**：工具模块采用插件化设计，新增工具不影响现有功能
- **NFR-E-002**：前后端分离架构，支持独立扩展

### 4.5 兼容性要求

- **NFR-C-001**：后端兼容 Go 1.24+ 版本
- **NFR-C-002**：前端兼容主流现代浏览器（Chrome、Firefox、Safari、Edge）
